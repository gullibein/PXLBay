# Repository Rules & Instructions

## Git Workflow
- **NEVER execute `git push`**: Do not run `git push` via automated tools/commands. The user must manually run `git push` in their own terminal for authentication and control.
- You may stage (`git add`) and commit (`git commit`) changes when requested, and inform the user when the commit is ready for them to push.
- **"Let's push pxlrogue"**: When the user says "Let's push pxlrogue", only stage and commit the following three files in `system_folder/PXL_folder/PXLRogue/`:
  - `index.html`
  - `playtest.html`
  - `spritesheet.png`
